# What Laurence learned as a system admin

A diary — running notes, entry per session, of the technical things Laurence
bumped into while standing up the hub on his phone with Claude.

Each entry follows the same shape:

- **Situation** — what we were trying to do, what broke
- **What Laurence suggested** — his instinct / brief / correction
- **The tech** — frameworks, hosts, URL schemes, APIs actually used
- **Snippet** — the small piece of code that matters, inline
- **Whole example** — link to the live rendered page on the hub
- **What I additionally incorporated** — new layers added on top of existing ones, without breaking the previous version
- **Version stamps** — which files changed and at what version

Entries are named `YYYY-MM-DD-<short-title>-vN.md`, newest first.
