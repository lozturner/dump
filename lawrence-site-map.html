Edges · how the pieces talk

  • /home/user/dump ──▶ tldr-session-map.html  ·  filesystem containment. The folder holds the file.
  • /home/user/dump ──▶ lawrence-site-map.html  ·  same — peer file in the same root.
  • tldr-session-map.html ┈┈▶ 4 internal threads  ·  logical, not filesystem. The threads live inside the HTML, not on disk.
  • .git/ ┄┄▶ claude/create-site-map-t4Un7  ·  virtual spin-up. A branch is a parallel copy of the whole tree.
  • .git/ ┄┄▶ claude/fix-execution-stack-DWPYZ  ·  another virtual spin-up. Same root, different history.
  • /home/user/dump ┈┈▶ assets/ · pages/ · docs/  ·  ghost edges — these folders aren't real yet, but the map reserves the slot.

If you add a sub-folder later

The ghost nodes on the map show where new branches in the file tree would attach. A typical growth shape would be:
  • assets/css/ and assets/img/ ──▶ referenced by HTML files via <link> / <img>.
  • pages/*.html ──▶ linked from this site map via <a href>, turning edges from "name mentions" into real hyperlinks.
  • docs/*.md ──▶ reference material, not served — connected by name only.
  • Each new git branch is another green dotted edge off .git/ — no filesystem change, just another parallel view.
