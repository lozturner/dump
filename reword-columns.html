Reword Column Method · v0.1

Same message, different audience. Pick one box per column, trace the line.
Answer the question: "What did you have for dinner?"
—
Method. Each column is a slot in the sentence. Each box is one way to fill that slot for a given audience. You pick one box per column; the line you trace is your version of the sentence. Same meaning — different words, different register, different listener. Like algebra: columns are variables, boxes are values. The "preset" rows are worked examples — child / adult / waiter — each a clean line through all ten columns.
prototype · single file · drag-free · keyboard: 1-7 to pick, ← → to move column
