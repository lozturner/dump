Project 01

Research Scaffolder

Substitute exec function · life-decisions engine

You feed it a decision ("when do I move out of the Portsmouth council flat", "when do I file the complaint", "when do I collect evidence") and it works the answer out the way you would if the executive-function bit of your brain was working.

Core loop
  • Input: the decision framed as variables (situation, constraints, deadline, risk tolerance).
  • Engine: multi-shot — variables → search → match → recommend.
  • Output: a recommendation backed by citations, not vibes.
Citation rules (non-negotiable)
  • Textbooks preferred over web links.
  • Every cited fact shows: bibliography entry + specific chapter/page + pasted excerpt in [brackets].
  • Web search allowed as fallback; still cited with excerpt.
TBD before build →
viewpoint (form-first? wizard? single long page?) · colour · how the citations render (footnote / sidebar / inline) · whether variables are typed forms or free-text.
Project 02

LLM Whack

Leaderboard · prompt × model × output

A Mickey-Mouse-simple AI chat button fronting a leaderboard of prompts that generate things across LLMs. Current #1: liminal space. Claude renders it as a fully walkable 3D room; Grok, Gemini, GPT each render it differently. The point of the site is to show which model wins per prompt.

Mechanics
  • Single prompt input at the top. One-click generate.
  • Grid of outputs — one cell per model (Claude / Grok / Gemini / GPT).
  • Leaderboard ranks prompts by how strong their outputs are across models.
  • Submit-a-prompt flow; voting on outputs.
  • Extensible: same pattern applied to company websites, product pages, etc.
TBD before build →
viewpoint (arena/grid/scrolling feed?) · how 3D outputs embed · colour · is this static-leaderboard demo or wired to real model APIs?
Project 03

Pokedex — Personal Lawrence Turner

Catalogue · flick through · add at leisure · export JSON

An index of every tool, idea, concept, and app you've built or want to build — rendered as cards you flick through like a Pokedex. Fallback position for anything that isn't fully built yet: the entry still lives here as a skeleton.

Card content

Behaviour

Project 04

Evidence Organiser (Legal)

AI does what a solicitor does with your paperwork

Same brief as the thing your brother did for family: feed in videos, documents, chats; AI picks out the salient bits, timestamps them, stacks them into bundles, writes a summary a lawyer could use.

Pipeline
  • Intake — video / audio / PDF / screenshots / chat exports.
  • Transcribe + OCR + chunk.
  • Salient-moment extraction — timestamps, quotes, faces-on-camera, raised voices.
  • Bundle builder — chronological, thematic, or per-allegation.
  • Export — PDF bundle, cited summary, timeline.
If full build isn't possible
  • Pseudo-code the pipeline.
  • Web search the market — what free / open-source tools already do parts of this.
  • Infer missing features from descriptions of popular paid apps; feed those into an LLM to scaffold the gaps.
TBD before build →
viewpoint (timeline / case-file / inbox-style?) · colour (legal-grey and navy, or break that?) · how redaction is visualised · which of the pipeline stages we actually build first.
Project 05

Mermaid Flow Studio

Every tool as an interactive, clickable, pannable flow

You don't like console output. You don't like JSON on the screen. You want every tool rendered as a Mermaid-style flow diagram, wrapped in HTML, interactive. This is the tool that makes that.

Viewer mode
  • Pan, zoom, click any node.
  • Nodes animate in, in index order, as the diagram loads.
Edit mode
  • One compressed edit button flips it to editable.
  • Drag nodes; re-wire connections; change connection settings.
  • Add new nodes.
  • Freeze button — saves the layout to permanent space.
  • Export — JSON of the full graph.
TBD before build →
viewpoint (fullscreen canvas vs. diagram + side panel) · node/edge aesthetic (hand-drawn / boxy / rounded) · colour per node-type · whether built on Mermaid.js or a custom SVG engine.
Project 06

Swiss Army Knife (the shell)

Not an OS · a desktop that feels like one · all applets in one place

The main object. One browser page that behaves like a lightweight desktop — start menu, taskbar, clock, windowed apps — and hosts every applet below. The metaphor is the Swiss Army knife: one handle, many tools, no separate apps to open.

Built-in applets
  • Browser (embedded).
  • Notepad (multi-note, persistent).
  • Clock (taskbar + fullscreen app).
  • Calendar (month view, clickable days).
  • Start menu / all-star items.
  • Desktop — persistent files/notes/sketches pinned to the background.
  • Drawing board · whiteboard · sketch pad.
  • Address book.
  • Emoji shortcuts.
  • Quick statements (snippets / canned phrases).
Integrations
  • Projects 01–05 launch as windowed applets inside here.
  • Desktop remembers state across reloads.
TBD before build →
viewpoint (Win95 homage / macOS-ish / brutalist original / CRT retro) · colour palette · window chrome · how many applets ship in v1 vs. later · storage strategy.
